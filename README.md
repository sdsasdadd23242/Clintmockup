# Vac to the Future - HVAC Company Website

This is a 3-page responsive website for an HVAC company called "Vac to the Future" with a Back to the Future-inspired design theme.

## Pages

1. **Home** - Company introduction, call-to-action, and "Why Choose Us" section
2. **Services** - List of HVAC services with icons and descriptions
3. **Contact** - Contact form, Google Maps integration, and social media links

## Design Features

- **Back to the Future-inspired color scheme:**
  - Midnight blue (#0C1B33) background
  - Neon orange (#FF6E00) for buttons and accents
  - Electric yellow (#FFE500) for headings
  - Light gray (#E0E0E0) for body text

- **Typography:**
  - Orbitron font for headings (futuristic style)
  - Roboto for body text

- **Responsive Design:**
  - Mobile-first approach
  - Responsive grid layouts
  - Hamburger menu for mobile devices

## Technical Features

- Semantic HTML5 structure
- CSS3 with custom properties (variables)
- Responsive layouts using CSS Grid and Flexbox
- Form validation with JavaScript
- Google Maps integration
- Social media links
- Scroll animations
- Mobile navigation menu
